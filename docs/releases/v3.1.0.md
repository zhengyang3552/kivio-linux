## 新版本亮点 / What's New

以下是 **v3.0.1 → v3.1.0** 的变更。These changes cover **v3.0.1 → v3.1.0**.

### 主题与墨墨桌宠 / Themes and Momo desktop pet

- **主题库 / Theme library** — 新增独立主题设置，十二套内置主题均含浅色与深色色板；支持自定义颜色、实时预览及 JSON 导入导出。刷新首屏恢复上次应用的主题，减少加载时的颜色跳变。Add dedicated theme settings with twelve built-in light/dark palettes, custom colors, live previews, and JSON sharing. Restore the applied palette at startup to reduce loading flashes.
- **原生桌宠 / Native desktop pet** — 墨墨可在 macOS 与 Windows 桌面显示思考、执行、回答、等待确认、完成和失败状态（**Linux 上不可用**：桌宠是 macOS / Windows 原生实现，开关保持关闭并提示 “Native desktop pet supports macOS and Windows”）；支持拖动、点击互动、双击打开对应聊天及右键隐藏。默认关闭，可从侧栏账号菜单或托盘开启，开关和位置保存在本机。Momo reflects assistant activity on the desktop, supports dragging and interaction, opens its chat on double-click, and hides on right-click (**unavailable on Linux**: the pet is a macOS/Windows native implementation and enabling it reports “Native desktop pet supports macOS and Windows”). Disabled by default; enable it from the account menu or tray, with visibility and position saved locally.
- **轻量陪伴 / Lightweight companion** — 闲置动作、短句气泡与今日用量播报复用本地状态，不调用模型、不增加 Token 费用；隐藏或减少动态效果时停用相应动画。Idle gestures, short speech bubbles, and daily usage messages use local state without model calls or extra token costs; hiding the pet or enabling reduced motion stops the relevant animations.

### 媒体站与作品 / Media station and works

- **图片与视频创作 / Image and video creation** — 新增媒体站，分离创作与历史视图，提供起步灵感、画幅选择、生成中占位画布和原生视频适配；视频结果加载首帧但不自动播放。Add a media station with separate creation/history views, starter ideas, aspect-ratio selection, generation placeholders, and native video adapters. Video results show a first-frame preview without autoplay.
- **创作管理 / Creation management** — 创作记录支持单条与批量删除，失败项保留反馈；页面切换后继续观察提交结果并保留草稿。Creation history supports individual and batch deletion with failure feedback, while submissions and drafts survive navigation.
- **文件引用保护 / File-reference safety** — 改进历史图片、生成文件及预览引用；清理消息或回退时统一对账附件路径，避免删除仍被引用的生成文件。Improve historical image, generated-file, and preview references; reconcile attachment paths during deletion and rewind to preserve files still in use.
- **流式 SVG / Streaming SVG** — SVG 图形可在生成中逐步预览并切换源码；标签、属性或字符实体尚未完成时保留已有画面。Preview SVG graphics progressively while streaming and switch to source view; incomplete markup preserves the last usable picture.

### 任务、自动化与扩展 / Tasks, automation, and extensions

- **任务中心 / Tasks center** — 定时任务与工作流自动化分别管理，共用任务页标签；定时任务向绑定对话发送提示词，自动化由触发器、动作和逻辑节点运行。Manage conversation schedules and workflow automation in separate tabs: schedules send prompts to a bound conversation, while automations run trigger/action/logic graphs.
- **通过对话创建 / Create via chat** — 两类任务均可打开新对话并预填创建请求，同时保留手动创建入口；预填不会自动发送。Both task types can open a new chat with a creation request prefilled, alongside manual creation; prefilling does not send the request.
- **自动化生命周期 / Automation lifecycle** — 完善草稿保存、失败重试、运行记录和离开后恢复；返回画布保留编辑，迟到读取不覆盖新内容。Improve draft saving, retry, run history, and navigation recovery; preserve edits when returning and reject stale reads that would overwrite newer content.
- **统一插件入口 / Unified plugin entry** — 整合插件市场与导航，补充 Claude 插件发现、原生 Skill 路由及行内命令展示；优化插件、技能和设置图标。Unify marketplace navigation, add Claude plugin discovery, native skill routing, and inline command chips, and refresh plugin, skill, and settings icons.
- **跨页面任务 / Work across pages** — 技能与插件安装、模型下载、媒体提交、原生会话导入和对话库批量操作在当前窗口内持续执行，返回后可查看进度、结果或错误。Keep installations, downloads, media submissions, native-session imports, and library batch operations running across navigation within the same window, with progress and results available on return.

### 聊天与运行时 / Chat and runtimes

- **长对话体验 / Long conversations** — 按需加载历史，隔离已完成消息与流式渲染，改进滚动锚点和会话切换后的阅读位置；收紧标题目录和思考展示，减少重排与首轮完成闪烁。Load history on demand, isolate settled messages from streaming updates, and preserve reading anchors across conversation switches; compact outlines and reasoning displays reduce reflow and completion flashes.
- **上下文压缩 / Context compaction** — 改进压缩快照回放、摘要失败处理和工具定义被拒后的重试；回退时重置压缩熔断状态。Improve snapshot replay, summary failure handling, and retries when tool definitions are rejected; reset compaction failure state on rewind.
- **待办清单 / Todo lists** — 重构 Todo 工具，清单不再重复放进系统提示词；提醒和历史回退保持一致。实时待办版本不被旧读取覆盖，执行工具后仍有未完成项时，结束前最多提醒一次。Rework todo tools without repeatedly embedding lists in the system prompt; keep reminders consistent with history and rewind. Preserve live revisions over stale reads and send at most one closing reminder for unfinished items after tool use.
- **外部 CLI 会话 / External CLI sessions** — 「回到这里」对齐外部 CLI 的原生会话；补齐 Claude Code 与 Codex 的协议适配、交互和计划档行为，强化只读沙盒、工具名匹配与异步答复索引。Realign external CLI native sessions on rewind; improve Claude Code/Codex protocol handling, interaction, and plan mode, including read-only sandboxing, exact tool-name matching, and asynchronous answer indexes.
- **键盘与交互 / Keyboard and interaction** — 改进弹出菜单键盘导航、Escape 关闭、应用内确认框及自定义问题输入；补齐工具卡本地化并修正含 `$` 文本的展示。Improve keyboard navigation, Escape handling, in-app confirmations, and custom answers; expand tool-card localization and preserve literal `$` sequences.

### 模型与用量 / Models and usage

- **模型目录 / Model catalog** — 更新十月模型目录与能力、上下文和计价信息，补充 GPT-6.1 Sol、Sonnet 5.5、MiniMax M3.1 Flash Preview 等记录；修正 MiniMax 输出上限与 Sonnet 思考设置。Refresh October model capabilities, context limits, and pricing, including GPT-6.1 Sol, Sonnet 5.5, and MiniMax M3.1 Flash Preview; correct MiniMax output limits and Sonnet thinking settings.
- **请求与统计 / Requests and statistics** — 统一模型请求与声明的客户端身份，改进用量页布局，使统计内容适配设置窗口。Align model requests with their declared client identity and resize usage statistics to fit the settings window.

## 验证说明 / Verification note

本分支在发布前先修掉上游 v3.1.0 遗留的 Node 20 前端测试兼容问题：`Promise.withResolvers`（ES2024）在 CI 的 Node 20 / jsdom 下不存在，导致 `ArtifactsCenter.test.tsx` 与 `MediaStation.test.tsx` 共 19 个用例失败。这里改用手写的等值 deferred（与上游 v3.1.1 的修法一致），发布前前端测试、Rust 测试与打包工作流均为绿色。This branch repairs, before publishing, the Node 20 frontend-test compatibility problem left over from upstream v3.1.0: `Promise.withResolvers` (ES2024) is absent under CI's Node 20 / jsdom and failed 19 cases in `ArtifactsCenter.test.tsx` and `MediaStation.test.tsx`. An equivalent hand-written deferred is used instead (the same repair upstream shipped in v3.1.1), so frontend tests, Rust tests, and packaging were green before this release.

同时修复 Linux 上 Rust 测试的偶发失败：授权回调测试原先断言回调端口关闭后“连接必须被拒绝”，但并行用例可能拿到刚释放的同一临时端口；现改为探测该端口不再由回调服务器应答。Also stabilizes a Linux-only Rust flake: the Antigravity callback test asserted that the closed port refuses connections, but a parallel test can be handed the same freed ephemeral port; it now probes that the port no longer answers as the callback server.
